# Laboratorio 1 - Primer Pipeline de Integración Continua

Este repositorio contiene la resolución del Laboratorio 1, en el que se implementa un pipeline de CI sencillo utilizando GitHub Actions.

## Acerca del Proyecto

Este proyecto es parte del Diplomado en el Módulo 4. En este laboratorio exploramos:
- Estructura básica de pipelines CI/CD.
- Configuración de Actions.
- Flujo de trabajo basado en Ramas y Pull Requests (Laboratorio 2).

## Estructura del repositorio

- `app/`: Contiene el código fuente y archivos de prueba.
- `.github/workflows/`: Contiene la definición del pipeline CI/CD.
